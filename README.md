# serials

A small PHP and MySQL application for storing and searching serial number
entries.

## What it does

- Lists stored entries a page at a time.
- Searches entries through an Ajax request (`ajax.js`).
- Adds new entries to the database.

## Tech

- PHP and MySQL
- JavaScript (Ajax)

## Running

Serve the folder with a web server that has PHP, and a MySQL database where the
code uses one (see `connect.php` or `db_mysql.php`).
